# KennisBoost Tools — Architecture & Feature Implementation Record (10-20-2026)

## Overview & Executive Summary

This release completes the comprehensive 6-Phase architectural expansion and hardening of KennisBoost Tools as a zero-trust, local-first learning management system. It brings full mobile and desktop accessibility, dedicated class and roster management, zero-server course feeds and curriculum units, an interactive calendar with .ics export, an automated inbox watch folder with auto-import capabilities, and anti-lookahead time-gated video transcripts with offline fallback.

---

## 1. Phase-by-Phase Implementation Summary

### Phase 0: Foundations, Storage & Cryptographic Hardening
- **Unified Due Dates (`src/core/due-dates.js`):**
  - Canonical cross-content due date resolver supporting assignments, video assessments, flashcard decks, timelines, and course items.
  - Automatically synchronizes linked `gradebook_assignments.due_date` records when matched by content type and ID.
  - Dispatches `kb-due-dates-changed` window events for reactive UI refreshes.
- **Gradebook Bridge (`src/modules/gradebook/bridge.js`):**
  - Line 47 hardened so explicit `dueDate !== undefined` takes absolute precedence over existing values.
- **App URL Resolution (`src/core/app-url.js`):**
  - Hierarchical resolution order: `config.json` -> `app_metadata.app_url` -> non-local window origin -> `null`.
- **Dexie Schema v6 & Content-Addressed Blobs (`src/core/storage.js`):**
  - Schema v6 adds `course_units`, `course_items`, and `student_items`.
  - Registered tables into `DATA_TABLES` with automatic `teacher` vs `student` scope separation.
  - Implemented `saveContentAddressedBlob(blob)` keyed by `sha256-<hex>` in OPFS and IndexedDB for cross-tool media deduplication.
  - Backup & replication engine updated to include all unit and item tables in `BACKUP_TABLES` and `SYNC_TABLES`.
- **Course Revisions & Feed Hashing (`src/core/course-revision.js`):**
  - Deterministic SHA-256 payload hashing for curriculum updates.
  - Tracks unit order and item revision timestamps, setting `feed_dirty = true` on course modifications.
- **Summative vs Formative Pipeline Hardening (`src/modules/assignments/grading.js` & `pipeline.js`):**
  - `buildStudentPayload` strictly strips all answer keys, check hashes, and `payload.reveal` when `feedback_mode === 'none'`.
  - Assignment Editor includes Formative Practice vs Summative Assessment presets and due-time inputs wired to `setDue`.
- **Interaction Telemetry & Commitment Schemes (`src/modules/assignments/take.js` & `pipeline.js`):**
  - Captures SHA-256 interaction hash chains (`question_viewed`, `answer_changed`, `paste_detected`, `tab_hidden`, latency).
  - Evaluates `integrity_flags` (`rapid_completion`, `paste_heavy`) inside the teacher's grading pipeline.
  - Supports loading assignment items directly from `student_items` via `?itemId=`.

### Phase 3: Course Curriculum Hub, Feeds & Student Portability
- **Curriculum Builder (`src/modules/course/index.js`, `render.js`):**
  - Unit builder with drag-and-drop item reordering and due date editing via `setDue`.
  - Item picker linking assignments, videos, flashcard decks, timelines, and external links.
  - Zero-server PBKDF2 + AES-GCM encrypted course feed publishing (`PublicFeedTransport`).
- **Relay Server Public Feeds (`server/relay/index.js`, `db.js`):**
  - `PUT /api/feed/:courseId` (teacher authenticated) and `GET /api/feed/:courseId` (public with ETag / 304 Not Modified).
- **Student Course Portal (`src/modules/student/courses.js`, `course-detail.js`):**
  - Course enrollment via class access codes.
  - Unit outlines with progress badges driven by `student_ledger`.
- **Chromebook Student Session Portability (`src/modules/student/session-portability.js`):**
  - 1-click **"Save Session (.kbsession)"** and **"Resume Session"** on Student Hub.
  - Packages enrolled courses, items, ledger history, keychains, and active drafts into an encrypted bundle for shared/ephemeral Chromebooks.

### Phase 5: Sharing, Submission Inbox Watch Folder & Gated Video Transcripts
- **Inbox Watch Folder & Auto-Import (`src/modules/inbox/index.js`):**
  - Directory polling via `window.showDirectoryPicker()` every 4 seconds.
  - Dual modes:
    - **Default (Stage & Review):** Stages incoming `.kbsub`, `.kbsub.html`, `.kbr`, and `.zip` files in the table for "Import all".
    - **Auto-Import Toggle:** Persistent `sl-switch` (`app_metadata.inbox_auto_import`) that immediately imports submissions and fires a completion toast.
- **Time-Gated Video Transcripts (`src/modules/video/interceptor.js`, `index.js`):**
  - Parses timestamped narration lines, SRT, and WebVTT into structured segments.
  - Anti-lookahead gate: slices after the earliest incomplete checkpoint (`t > nextIncomplete.timestamp_sec`) are locked and redacted.
  - Segments unlock progressively as checkpoints are answered (`resolveCheckpoint`).
  - Zero-network **Offline Fallback Mode** allows students to proceed through checkpoints sequentially even if video streams are blocked.
- **Optical QR Stream Presenter & Scanner (`src/components/share-dialog.js`, `src/modules/student/index.js`):**
  - High-throughput `KBQ1` animated QR stream projection for air-gapped classrooms.
  - Student Hub "Scan QR" button with continuous optical camera scanner.
- **Accessible Timelines (`src/modules/timeline/index.js`, `svg-exporter.js`):**
  - Added semantic `role="list"` chronological event feed below canvas with keyboard navigation.
  - Enriched SVG exports with `role="graphics-document"`, `<title>`, and `<desc>`.
